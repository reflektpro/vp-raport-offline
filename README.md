# ГУ ВП · автономные бланки (без Discord)

Автономная копия сайта бланков ГУ ВП. Работает целиком в браузере: открой `index.html` прямо с диска (file://)
или выложи папку на любой статический хостинг. Нет входа, нет отправок, нет внешних запросов
(шрифты, картинки и библиотеки лежат в репозитории).

## Страницы

| Файл | Документ |
| --- | --- |
| `index.html` + `app.js` | Рапорт на взыскание (новая структура: I–III, пункты 1–10, ходатайство) |
| `otchet.html` + `otchet.js` | Еженедельный отчёт (рапорт о результатах служебной деятельности за неделю) |
| `povyshenie.html` + `povyshenie.js` | Рапорт о присвоении очередного воинского звания (калькулятор по `promo-rules.js`) |
| `vygovor.html` + `vygovor.js` + `vygovor-rules.js` | Приказ о дисциплинарном взыскании |
| `ugolovnoe.html` + `ugolovnoe.js` + `ud-docs.js` | Бланки дознавателя по уголовным делам |
| `gajd.html` | Гайд по уголовным делам |

На каждой странице две кнопки:

- **Скачать PDF** — настоящий PDF A4 с векторным текстом (кириллица извлекается и ищется),
  все ссылки (доказательства и т. п.) видны в тексте и кликабельны.
- **Скачать PNG** — тот же документ, отрисованный в картинку A4 (1588×2246 px на лист), но **без ссылок**:
  вместо адресов «Приложение №N» (или только название материала). Многостраничный документ — по файлу на лист.

Со второго листа номер страницы посередине верхнего поля. Девиз «ГУ ВП — ЗАКОН. ПОРЯДОК. ДИСЦИПЛИНА.» — внизу последнего листа рапортов.

## Как устроено

- `docs.js` — ядро: описание документа (шапка, «Кому», заголовок, разделы, пункты, подпись) → pdfmake → PDF;
  для PNG тот же документ собирается без ссылок и рисуется pdf.js в canvas. Живой предпросмотр справа от формы
  (переключатель PDF/PNG).
- `criteria.js` — панель критериев для отчёта и повышения (основные/дополнительные + свои пункты).
- `promo-rules.js` — виды работы, баллы, ступени повышения. Поле `group: "main" | "extra"` решает, в какой пункт
  (4 — основные, 5 — дополнительные) попадает вид работы. **Разбивка предварительная** — меняется одним полем.
- `config.js` — шапка, строка части, адресат «Кому», девиз.
- Номер документа — локальный счётчик в браузере (localStorage), поле редактируется вручную; кнопка «след.»
  подставляет следующий. Свои данные (звание, ФИО, должность, статик) и черновики запоминаются в браузере.
- Приказы: по паспорту показываются приказы, выгруженные ранее в этом же браузере.

## Библиотеки и шрифты (в репозитории)

- `vendor/pdfmake.min.js` — pdfmake 0.2.23 (MIT), сборка PDF с встраиванием шрифтов и ссылками.
- `vendor/pdf.min.js`, `vendor/pdf.worker.min.js` — pdf.js 3.11.174 legacy (Apache-2.0), отрисовка PNG
  (воркер подключён обычным скриптом, поэтому работает и с file://).
- `fonts/` — подмножества Tinos (Apache-2.0, метрика Times New Roman), Marck Script и Oswald (OFL).
  `vendor/fonts-data.js` и `assets-data.js` (герб, печать в base64) собираются `python3 tools/build-data.py`.

## Хостинг

Подходит любой статический хостинг (например, отдельный репозиторий с GitHub Pages: Settings → Pages →
Branch: main). Серверная часть не нужна.
